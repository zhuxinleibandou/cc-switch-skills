# 选片

## 评分表（每项 0–3 分，满分 21，≥14 推荐，10–13 勉强，<10 换片）

| 维度 | 3 分 | 0 分 |
|---|---|---|
| 一句话反常设定 | 一句话就让人想看（规则怪谈、身份反转、密室） | 需要大段背景才讲得清 |
| 可前置的强场面 | 有完整的高潮/结局戏可做 1–3 分钟冷开场 | 全片平淡、靠氛围 |
| 反转 | 结局或中段有明确反转 | 一条直线到底 |
| 题材传播性 | 恐怖/悬疑/犯罪/怪谈/偏执爱情/人性实验 | 文艺、慢热、强依赖台词的喜剧 |
| 热度 | 近 3 个月上映/上线，或经典 IP 有新作 | 冷门且无话题 |
| 画面可用 | 1080p、无硬字幕或硬字幕可接受、画面辨识度高 | 低清、全程暗、硬字幕挡画面 |
| 可连载 | 剧集或系列，可做合集 | 单片且无续作 |

## 题材优先级（对照三条爆款）
1. **规则怪谈 / 密室 / 生存游戏**：规则本身就是钩子引擎（午夜规则）。
2. **偏执爱情 / 人性悬疑 + 反转结局**：转发最高（造物狱）。
3. **知名 IP 的前传/新作**：用观众已知角色做钩子（水晶湖 → 杰森）。
4. 犯罪真实改编、灾难求生、怪物片。
5. 不推荐：纯文艺、歌舞、对白密集的喜剧、需要大量文化背景的历史剧。

## 调研步骤（上网）
1. 搜「近期热播 恐怖/悬疑 电影/剧集」「豆瓣 高分 反转」「抖音 电影解说 热门」看哪些片正在被解说、哪些还没人做（有人做过不代表不能做，但最好换钩子类型）。
2. 查梗概 + 结局 + 关键反转（维基、豆瓣、IMDb plot）。
3. 填评分表，输出：

| 片名 | 类型/年份 | 一句话钩子 | 推荐开头 | 分集 | 得分 |
|---|---|---|---|---|---|

## 分集
- 电影：90–110 分钟、单主线 → 1 期 10–13 分钟；110–150 分钟或反转密集 → 可拆上下两集（每集 8–12 分钟，上集停在中点大反转）；150 分钟以上强设定/多线大片 → 可拆上中下三集（每集 8–11 分钟，按剧情大转折切而非按片长均分，且每集都要有独立开场钩子、阶段性兑现与结尾续集钩子，中集避免只做铺垫）。
- 剧集：每集 40–60 分钟 → 每集 1 期 8–12 分钟；连续两集剧情弱时合成一期。
- 每期的结尾 = 下一期的冷开场素材来源之一，提前规划。
- 合集命名：「<片名>｜<一句钩子>」，如「午夜规则｜违反守则就会死」。

## 用户需要提供
- 原片视频文件（mp4/mkv，越清晰越好；剧集按集分文件）。
- 账号名（水印用）、偏好男声/女声（可默认）。
