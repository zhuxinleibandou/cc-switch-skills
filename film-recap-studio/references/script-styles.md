# 口播文案风格卡（2026-11-26 建立）

同一集素材可以出多套文案风格。流程：**选片 → prep → 看片建 beats → 选风格（可并行出多份口播稿给用户挑）→ 定稿写 script.json → 配音 → 剪辑**。
口播稿先只写纯文本（`口播稿-风格X-名字.md`，不配 clips），用户选定后再落成带 clips 的 `script.json`，避免白做剪辑工程。
`script.json` 顶层用 `style` 字段记录风格 id，便于同一账号保持统一或 A/B 测试。

## 怎么新增一张风格卡
1. 拿到参考账号的某一期链接，抓音频转写成文字稿（方法见本文末「取样方法」）。
2. 从转写稿里量四件事：**开场前 15 秒怎么抓人、句长与语速、第一人称是否出现、原声占比与留白时长**。
3. 再记三件事：**固定句式与口头禅、分析/吐槽/叙事的配比、结尾落点**。
4. 按下面格式写成一张卡，标上参考来源与实测数据。

## 选片时就推荐风格（2026-11-26 用户定的协作方式）

用户只给片名时，**在选片评分之后、看片之前**就出一条风格推荐，和分集建议一起给。判断只看五件事，都能从剧情梗概和结局里读出来：

| 判断维度 | 怎么问 | 偏向 |
|---|---|---|
| 1. 反转强度 | 结局有没有一个「原来如此」的大翻盘？ | 有 → **A**（结局前置最吃反转） |
| 2. 主角处境 | 主角是不是被生活/体制欺负的普通人，观众会替他憋屈？ | 是 → **B** |
| 3. 可分析性 | 人物有没有说不出口的动机、心理创伤、道德撕裂？ | 有 → **C** |
| 4. 剧情密度 | 事件多到讲不完，还是一集只有几场戏但很深？ | 事件多 → A/B；戏少而深 → **C** |
| 5. 体量与连载 | 单集 or 长剧连载？要不要留回头客？ | 连载、要黏性 → **C**；单片、要完播 → **A/B** |

常见题材的默认落点（有冲突时按上表逐条压）：

| 题材 | 首选 | 理由 |
|---|---|---|
| 规则怪谈、密室、恐怖 | A | 靠悬念和信息差，一分析就不怕了 |
| 悬疑推理、犯罪反转 | A | 结局前置 + 首尾闭环 |
| 小人物逆袭、复仇、职场压迫 | B | 共情和「爽」是主要驱动 |
| 人物剧、政治惊悚、文艺片 | C | 卖的是人性命题不是情节 |
| 经典重温、高分长剧连载 | C | 粉丝要的是「讲出我说不出的那层」 |
| 爆米花动作、灾难片 | B | 节奏快、情绪直给 |

**输出格式**（一屏说完）：
```
推荐风格：C 深度解读流
理由：主角有一条说不出口的动机线（三条具体证据）；单集戏少但每场都能挖
备选：A（若你想先冲完播率）
不建议：B（主角不是被欺负的一方，替他鸣不平会跑偏）
```
全权限下直接按推荐往下走，并在 `script.json` 的 `style` 字段记下来。用户要比风格时，再按上面的流程并行出多份纯文本口播稿。

**风格库会持续长**：用户后续会继续发好视频来学。每来一条就按下面「取样方法」抓文案、量四件事、新增一张卡，并把它补进上面两张表（标清来源与实测数据）。同一题材可以有多张卡，这时在推荐里写明两张卡的差别让用户挑。

## A「冷静叙事流」（默认）
- **id**：`calm-narrative`
- **来源**：此前韩剧／惊悚片解说路线，S01E01 已按此风格出片
- **开场**：结局前置或高潮前置，第 1 句 ≤20 字直抛最反常的一件事
- **人称**：不出现作者，全程第三人称；不说「大家好」「我」
- **句式**：短句，字幕 9–14 字一屏，用「就在这时／殊不知／然而／没想到／直到／可」推进
- **节奏**：每 30–60 秒抛一个悬念问题，不做价值评论
- **原声**：每 10 分钟 7–10 段，单段 3–15 秒
- **结尾**：停在最紧处 + 1–2 个钩子问题 +「我们下期再见」
- **适合**：悬疑、惊悚、犯罪、规则怪谈；完播率导向
- **实测**：S01E01 共 3,491 字，成片口播 11:56

## B「吐槽共情流」
- **id**：`wry-empathy`
- **来源**：抖音【莫白电影】《绝命毒师》全集开讲 第1集（14:23，25.7 万赞）
- **开场**：先抛身份反差（「都说当老师是个体面活儿，可谁能想到……」），再倒回去讲
- **人称**：**作者在片中登场一次**，位置在冷开场之后（样片在 5:30 处），内容是自我介绍 + 作品背书（评分、奖项、剧名含义、角色外号来源），讲完立刻回正片
- **句式**：极短，口语俚语和网络梗（「哪哪都好」「窝囊气」「显摆」「差点干出心脏病」），允许「你猜他拿出来什么」这类直接对观众提问
- **节奏**：几乎每 2–3 秒一句，剧情推进极快；每隔一段插一句替主角鸣不平的评论（「这种窝囊气，换谁谁不难受」）
- **原声**：插得更碎更频，外语台词直接放原声不翻译，靠画面和前后文带
- **结尾**：一句金句收（样片：「人一旦不再害怕失去，就没什么能困住他」）+ 下集预告
- **适合**：主角有强烈「被生活欺负」底色的片子；共鸣和转发导向
- **注意**：样片为了情绪夸大了事实（编了工资数字和不存在的奖项）。**我们这边数字一律只用原片确有的，宁可不说也不编。**

## C「深度解读流」
- **id**：`deep-read`
- **来源**：抖音【心中之城】《贴身保镖》解说第一期（20:12，598 万赞）
- **开场**：不用结局前置，跟着主角的视线逐帧细读一场戏制造悬疑（「他看了看窗外，看到一个男人打完电话把手机掰碎」）
- **人称**：第一人称出现得很频繁但很轻——「我想」「我猜」「接下来都是我的猜测」「我在这里停了一会儿」；开场有固定台词「大家好，这里是【账号名】」
- **句式**：偏书面，允许长句和排比；每讲完一场戏就停下来分析人物动机
- **节奏**：慢，剧情 : 分析 ≈ 6 : 4；一个心理命题可以铺两三百字
- **原声**：留白最多，关键场次整段放原声不讲话（10 秒以上也可以）
- **结尾**：抛一个人性命题（不是剧情钩子）+「敬请期待第 X 期」
- **适合**：人物剧、政治惊悚、文艺片、经典重温；粉丝黏性和长完播导向
- **注意**：这是长视频路线（20 分钟量级），我们压到 12–14 分钟时要先砍剧情细节，保分析段，否则会变成「又长又平」

## 取样方法（抓参考账号的文案）
抖音网页端未登录也能取到音频流：
1. 用内置浏览器打开 `https://www.douyin.com/video/<modal_id>`（用户分享链接里的 `modal_id` 就是视频 id）。
2. 取播放地址：`document.querySelector('video').currentSrc`。若是 `blob:`（MSE 播放），改从 `performance.getEntriesByType('resource')` 里筛 `douyinvod`，`media-audio-und-mp4a` 那条就是纯音频流。
3. `ffmpeg -headers "Referer: https://www.douyin.com/" -i "<url>" -vn -ac 1 -ar 16000 -c:a pcm_s16le out.wav`
4. `mlx_whisper`（`mlx-community/whisper-large-v3-turbo`，`language='zh'`）转写，按 segment 带时间码落成 txt。
5. `yt-dlp` 走不通（报 `Fresh cookies are needed`），不用在它上面耗时间。
6. 转写只用来学风格：外语原声段会被 whisper 乱译，带时间码看位置就够，不要把它当事实依据。
