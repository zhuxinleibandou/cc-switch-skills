# 发布文案模板（写到 output/publish.md）

```markdown
# <片名> 第N集 · 发布包

成片：master_16x9.mp4（横屏 mm:ss）/ vertical_9x16.mp4（竖屏）
封面：cover_16x9.jpg（YouTube/西瓜）、cover_3x4.jpg（抖音/视频号）、cover_9x16.jpg（竖屏全屏）
字幕：subtitles.srt（YouTube 可上传为字幕轨）
合集：<片名>｜<一句钩子>

## 抖音（横屏 master 或竖屏 vertical；封面 3:4）
标题候选：
1. <第一句反常事实>，<片名>第N集
2. <悬念问题>？
3. <数字/身份反差>
简介：一句钩子 + #片名 #电影解说 #恐怖片 #悬疑 #影视解说
挂合集；评论区置顶：「你能活过几条规则？」类互动问题

## 视频号（横屏优先；封面 3:4）
标题 ≤ 30 字，偏叙述；话题 3–5 个；加入合集

## 西瓜视频（横屏；封面 16:9）
标题 ≤ 30 字，可带「一口气看完」「第N集」；分区：影视→电影解说

## YouTube（横屏；封面 16:9；上传 subtitles.srt）
标题：<中文标题>｜<片名英文/原名> 解说 EP.N
描述：剧情一句话 + 章节时间戳（从 timeline.json 的 beat 生成）+ 标签
标签：电影解说, 影视解说, <片名>, <原名>, horror movie recap

## TikTok（竖屏；中文受众用中文，外文受众需另配音/字幕）
标题短 + 3 个标签；首帧即冷开场

## 下集预告
<下集冷开场用哪段、第一句是什么>

## 发布前人工确认
- [ ] 完整看过一遍、听过混音
- [ ] 授权/版权已处理
- [ ] 平台原创声明按实际勾选
```

## 写法要点
- 标题 = 第一句话的变体，不要和封面字一模一样（封面短、标题长）。
- 三个候选覆盖三种钩子：反常事实 / 悬念提问 / 数字反差。
- YouTube 章节：timeline.json 每个 beat 第一次出现的时间 → `00:00 开场`、`01:14 片名` 等。
