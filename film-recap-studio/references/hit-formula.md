# 爆款写稿公式（来自抖音 @探手电影 三条爆款，2026-11-23 拆解）

| | 造物狱（《黑盒子》） | 午夜规则 第1集 | 水晶湖 第一二合集 |
|---|---|---|---|
| 时长 | 12:54 | 10:20 | 23:17 |
| 点赞 / 收藏 / 转发 | 149.7万 / 17.6万 / 120.9万 | 49.4万 / 9.9万 / 31.8万 | 8.4万 / 1.6万 / 1.7万 |
| 开头钩子 | 结局前置 + 反转 | 高潮前置 | IP 前传 |
| 平均镜头 | 3.6 秒 | 1.5 秒（开场 0.92） | 2.8 秒 |
| 片名出现 | 3:12 | 1:14 | 0:08 |

结论：**转发最高的是"结局前置 + 首尾闭环"**；两集合一的长合集互动明显弱，单集 10–13 分钟最稳。

## 一、六条共同套路

1. **第一句 = 全片最反常的一件事**（≤20 字，最好带数字、谐音、身份反差）
   - 「为了防止男友劈腿，女人劈掉他的双腿」（造物狱 0:00）
   - 「她突然发现眼前的顾客可能不是人」（午夜规则 0:00）
   - 「他明明才八岁，母亲却送给他一把大砍刀当生日礼物」（水晶湖 0:00）
2. **冷开场讲成一个完整小故事**，结尾给反转，然后才报片名。
   - 造物狱 0:00–3:11：被囚男友藏头发编绳、藏鸡骨做钩、拧螺丝逃到门口 → 外面站着另一个自己 → 原来自己只是木雕。
3. **片名一句 + 世界观三句**，马上回正片。
   - 「这便是最新上映的泰剧《午夜规则》。一家专门接引死者的便利店，13 条员工守则，违反任何一条都会死，而鬼会想尽办法引诱你违反。」
4. **每 30–60 秒抛一个问题**，或用"规则编号/倒计时"制造等待。
   - 「但为何会变成令人闻风丧胆的杀人魔」「心中已经酝酿出了一个逃跑计划」「员工守则第七条：使用微波炉时禁止回头」
5. **短句推进**：一屏字幕 9–11 字；转折词：就在这时 / 下一秒 / 殊不知 / 然而 / 没想到 / 直到 / 好在 / 可。先演结果再解释原因（先"他不敢回头"，再"因为守则第七条"）。
6. **留白给原声**：每 10 分钟 7–10 处 >2.5 秒原声（尖叫、关键台词、配乐）；造物狱结尾整整留了 28 秒原声。

**双结尾钩子**：剧情停在最紧处 + 1–2 个问题 + 「我们下期再见」+ 挂合集。
例：「帕姆的秘密是什么？是否与杰森的诞生有关？」「阿伦又会经历怎样离奇的事情，我们下期再见。」

## 二、三种开头怎么选

### A. 结局前置（造物狱型）—— 首选，有反转结局的片
- 0–3 分钟讲结局那场戏（含反转），单独看也成立。
- 片名后倒叙"她为什么会这样"，最后一句正好接回开头 → 观众想重看 → 完播与转发高。
- 情绪主线最好是人际关系（偏执的爱、背叛、亲情），比纯恐怖更能引发讨论。
- 节奏偏慢（3–4 秒/镜），给对白和表情留空间。

### B. 高潮前置（午夜规则型）—— 规则怪谈 / 连续剧单集
- 全集最强画面剪到第 0 秒，前 75 秒剪辑最密。
- 讲完高潮留一个尾巴（地上的断手），切「这便是…」。
- 主角困境三层叠加（失业 / 欠债 / 家人）→ 走投无路才入局，制造同情。
- 中段"规则 → 试探 → 惊吓/反转"循环，每条规则一个小钩子。
- 中后段回收开头那场戏。

### C. IP 前传（水晶湖型）—— 观众已知的角色/系列
- 不剪高潮，用观众熟悉的名字当钩子：先讲可怜的孩子，几秒内点出「造就了不死杀人魔杰森」。
- 好奇点是"他怎么变成那样的"。

## 三、10 分钟成片骨架（可直接套）

| 时间 | 段落 | 解说字数 |
|---|---|---|
| 0:00–0:05 | 第一句 + 最强画面 | 15–20 |
| 0:05–1:30（结局前置可到 3:00） | 冷开场小故事 + 反转 + 1 段原声 | 350–800 |
| +20 秒 | 片名 + 世界观三句 | 80–120 |
| 中段 | 主角困境 → 入局 → 每 30–60 秒一个问题→答案；2–3 次小反转；5–7 段原声 | 1500–2000 |
| 最后 1 分钟 | 回收开头 / 新危机 + 1–2 个问题 + 下期再见 | 150–250 |

## 四、语言细节
- 口语、零形容词堆砌；能用动词不用形容词。
- 数字具体化：「1 万泰铢、高 10 倍、13 条、凌晨 3 点」。
- 一句代入式金句，把故事拉回观众日常（「职场中老员工欺负新员工很常见」）→ 带评论。
- 人名少：主角用名字，配角用身份（"哥哥""经理""红衣女人"）。
- 不剧透结局真相（结局前置只放"发生了什么"，不解释"为什么"）。

## 五、包装
- 底部白字黑边字幕，关键词黄色高亮；左下/左上小水印；右上"内含恐怖元素 请谨慎观看"（提示兼钩子）。
- 去黑边放大（近 16:9 铺满），宽银幕保留黑边。
- 横屏 10 分钟以上吃中视频/长视频分成；竖屏版加顶部大标题投抖音/视频号/TikTok。
